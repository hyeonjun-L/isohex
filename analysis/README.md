# 상권 실험실 — 분석 스크립트

서울시 상권분석 서비스(1,650 상권 × 20분기)로 격자 작업 전에 같은 질문을 먼저 던진 코드다.
결과 해석은 프로젝트 문서 `점지-마스터플랜.md` §5에 있다.

## ⚠ v2 재검증 (2026-10-01) — 먼저 읽을 것

v1은 점포 수로 `점포_수` 열을 썼는데, 이건 **프랜차이즈를 뺀 일반 점포**였다.
전체는 `유사_업종_점포_수`(= `점포_수` + `프랜차이즈_점포_수`)다. 그래서 v1의
잠식률(73%, 업종별 7~98%)과 폐업률(편의점 11%)이 부풀었다.
`build_master.py`·`join_master.py`는 고쳤고, 점포수를 직접 쓰던 v1 스크립트(a8, a10~a12)에는
머리에 ⚠ 표시를 달고 v2 스크립트로 대체했다.

| 항목 | v1 | v2 |
|---|---|---|
| 잠식률 (전체) | 73% | **약 58%** (52~59%) |
| 업종별 범위 | 7~98% | **49~69%** (수축 후) |
| 편의점 분기 폐업률 | 11.4% | **3.1%** |
| 상권 SHP 좌표계 | 5186 | **5181** |

> **2026-10-10 수정** — `build_master.py`가 파일 패턴 `*점포-상권*`·`*추정매출-상권*`·`*영역-상권*`으로 찾다 보니
> 원본 폴더에 '상권배후지' zip이 함께 있으면 그것까지 섞였다(점포 152만 → 305만 행, 영역 SHP는 어느 쪽이 잡힐지 운). 패턴 끝에 `)`를 붙여 막았다.
> 이전 결과는 배후지 zip이 없던 폴더에서 만든 것이라 숫자는 그대로다. `v2_crosswalk.py`의 SHP 패턴도 같이 고쳤다

## 실행 — 한 번에

```bash
cd isohex/analysis
pip install pandas pyarrow pyshp statsmodels scipy shapely pyproj
./run_v2.sh        # 원본 zip 해제 → 패널 → v2 분석 전부 (약 3~5분)
```

- 원본 폴더는 기본값 `../서울시 상권분석 서비스`. 다른 곳이면 `SANGGWON_DIR=...`
- 크로스워크(`v2_crosswalk.py`)는 상가정보 스냅샷이 필요하다. 기본값 `../data/snapshots/poi_2026Q2.parquet`,
  다르면 `POI_PARQUET=...`
- 100m 격자는 `../격자통계/`(`SGIS100_DIR`), 생활이동은 `../수도권 생활이동/`(`MOVE_DIR`).
  생활이동은 2026-04-06~12, 06-01~07 두 주만 읽는다
- 빈 폴더에서 처음부터 돌려 문서의 숫자가 그대로 나오는 것을 확인했다 (2026-10-01)

## 산출물

- `업종별_잠식률.csv` — 52개 업종의 α(매력도 지수)와 잠식률(= 1−α), 95% 구간. **W3 Huff 매력도 지수에 그대로 쓴다**
  - `α_raw`: 업종별 8분기 차분 추정치 / `α`: 수축 후 / `w`: 자기 추정치에 준 가중치
- `상권_분기_패널.csv` — 1,650 상권 × 20분기 × 56열 (점포수 = 전체, `일반점포수` 별도)

## 읽을 때 주의

- `점포_수` ≠ 전체. 전체는 `유사_업종_점포_수`
- `당월_매출_금액`은 당월이 아니라 **그 분기 합계**다
- 추정매출은 **점포 1~2개 셀에서 비공개** — 첫 진입(0→1, 1→2) 효과는 외삽
- 2025년 파일만 **컬럼명이 영문**이다 (`stdr_yyqu_cd` …). `build_master.py`의 `EN2KO`가 처리
- 상권 SHP는 **EPSG:5181** (False_Northing 500000). 5186으로 읽으면 100km 남쪽
- 상권분석은 **100업종**, 소상공인 상가정보는 **247업종** — 크로스워크 필요 (`v2_crosswalk.py`)
- 독서실(CS200038)에는 추정매출이 없다. 매출 종속변수를 쓸 수 없는 업종이 37개
